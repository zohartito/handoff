# Retired desktop integrations

The former desktop shortcut and launcher integrations are removed. This source
directory retains only the local test runner and this tombstone notice; it does
not distribute a shortcut, launcher, wrapper, hook, or shell-out path for
operational Handoff behavior.

If a prior version installed a shortcut or launcher, remove that existing
registration through the operating system or launcher that owns it. Do not use
the frozen Handoff CLI to inspect or alter historical `.handoff` data.
